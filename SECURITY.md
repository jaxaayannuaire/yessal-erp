# Security Policy

## Reporting a Vulnerability

Ne publiez pas publiquement une vulnérabilité de sécurité.

Contactez directement l'équipe de développement Yessal ERP pour signaler :

- vulnérabilités d'authentification ;
- accès non autorisés ;
- exposition de données ;
- failles API ;
- problèmes liés aux paiements.

Les informations sensibles, mots de passe, clés API et fichiers `.env` ne doivent jamais être ajoutés au dépôt Git.
