# Contributing

## Branches

- `main` : version stable.
- `develop` : développement principal.
- `feature/*` : nouvelles fonctionnalités.
- `fix/*` : corrections.

## Commits

Utiliser des messages explicites :

- `feat: ajouter authentification`
- `fix: corriger connexion API`
- `docs: mettre à jour changelog`
- `refactor: réorganiser services`

## Règle

Toute modification importante doit mettre à jour :

- `CHANGELOG.md`
- la documentation concernée dans `docs/`
