# Yessal Caisse — Eloquent Models v0.1

Modèles correspondant aux migrations Caisse v0.1.

Namespace par défaut :
`App\Models\Caisse`

À adapter si le Core Yessal utilise une convention différente.

## Important
Les modèles supposent l'existence de :
- `App\Models\Organization`
- `App\Models\User`

Les modèles ne contiennent volontairement pas encore :
- Policies
- Observers
- Services métier
- Events
- API Resources
- logique de synchronisation

Ces éléments seront ajoutés après les tests métier.
